# Support

BorderCut is maintained as an open-source project on a best-effort basis.

Before requesting help:

1. Read the repository README and the relevant package README.
2. Reproduce the problem with the latest supported version.
3. Run `npm ci` and `npm run check` from a clean checkout.
4. Reduce the problem to the smallest image recipe or RGBA buffer that still demonstrates it.

Use a bug report for reproducible defects and a feature request for proposed behavior. Include the package version, runtime or browser version, operating system, options, dimensions, and a privacy-safe reproduction. Do not upload confidential images.

Security concerns belong in the private process described in `SECURITY.md`, never in a public support thread.
